# Design Patterns - Structural

Os Padrões de Projeto Estruturais (Structural Design Patterns) concentram-se em como objetos e classes são compostos para formar estruturas maiores, mantendo flexibilidade e eficiência.

Eles ajudam a organizar relações entre entidades, simplificando a construção e a manutenção de sistemas complexos.

### Características

- Objetivo: Definir maneiras de compor objetos e classes para criar estruturas reutilizáveis e escaláveis;
- Foco: Relações entre objetos, hierarquias e interfaces, garantindo baixo acoplamento e alta coesão;
- Benefícios: Simplifica a integração de componentes, melhora a escalabilidade e reduz a complexidade de sistemas.

### Aplicabilidade

Usados quando é necessário estruturar sistemas com muitos objetos, integrar componentes heterogêneos ou otimizar recursos sem comprometer a flexibilidade.

### Diferença com Padrões Comportamentais

Enquanto os padrões estruturais lidam com a composição (como objetos são organizados), os padrões comportamentais focam na interação (como objetos colaboram). Por exemplo, o padrão State (comportamental) gerencia mudanças de comportamento, enquanto o Composite (estrutural) organiza hierarquias de objetos.
