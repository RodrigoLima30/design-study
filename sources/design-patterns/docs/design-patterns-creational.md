# Design Patterns - Creational

Os Padrões de Projeto Criacionais (Creational Design Patterns) focam em mecanismos de criação de objetos, garantindo que a instanciação de classe seja flexível, controlada e adequada ao contexto do sistema. Eles abstraem o processo de criação, promovendo reutilização, escalabilidade e baixo acoplamento.

### Características

- Objetivo: Gerenciar a criação de objetos, simplificando como e quando eles são instanciados;
- Foco: Controle da instanciação, evitando dependências diretas e otimizando recursos;
- Benefícios: Reduz dependências, facilita a manutenção e permite maior controle sobre o processo de criação.

### Aplicabilidade

Usados quando a criação de objetos é complexa, precisa ser centralizada, ou deve ser flexível para suportar diferentes tipos ou configurações.

### Diferença com Outros Padrões

Criacionais: Lidam com a criação de objetos (e.g., como instanciar um Pedido);
Estruturais: Focam na composição de objetos (e.g., como organizar Pedido com outros objetos);
Comportamentais: Gerenciam a interação entre objetos (e.g., como Pedido muda de estado).
